# HTTP Analysis

## Objective

Understand web communication over HTTP.

## Theory

HTTP is an application-layer protocol used to transfer web content between clients and servers.

## Lab Setup

Display Filter:
- http

## Packet Analysis

Observed:

- HTTP GET Request
- HTTP 200 OK Response
- Host Header
- User-Agent
- Server Header

## SOC Relevance

HTTP traffic analysis helps detect:

- Malicious downloads
- Suspicious web requests
- Data exfiltration

## Key Takeaways

Learned how browsers request and receive web content.
