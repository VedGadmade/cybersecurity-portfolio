# TCP Analysis

## Objective

Understand TCP connection establishment.

## Theory

TCP provides reliable communication through the Three-Way Handshake.

## Lab Setup

Display Filter:
- tcp
- tcp.flags.syn == 1


## Packet Analysis

Observed:

- SYN
- SYN-ACK
- ACK
- Source Port
- Destination Port
- TCP Flags

## SOC Relevance

TCP analysis helps identify:

- Port scanning
- Connection failures
- Session establishment
- Network anomalies

## Key Takeaways

Learned how reliable communication is established before data transfer.
