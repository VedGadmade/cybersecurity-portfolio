# TLS Analysis

## Objective

Understand how encrypted communication is established.

## Theory

TLS secures network communication by encrypting data exchanged between a client and server.

## Lab Setup

Display Filter:
- tls.handshake

## Packet Analysis

Observed:

- Client Hello
- Server Hello
- Cipher Suites
- TLS Version
- Server Name Indication (SNI)

## SOC Relevance

TLS analysis helps identify:

- Certificate issues
- Encrypted malware communication
- Suspicious outbound connections

## Key Takeaways

Learned how TLS establishes secure communication before encrypted data exchange.
