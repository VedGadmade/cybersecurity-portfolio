| Port | Service | Description |
|---:|---|---|
| **22** | **SSH** | **SSH (Secure Shell)** is used for secure remote login and command execution. It encrypts communication using cryptographic protocols. |
| **80** | **HTTP** | **HTTP (Hypertext Transfer Protocol)** is used to transfer web resources between clients and web servers. Data is transmitted without encryption. |
| **443** | **HTTPS** | **HTTPS (Hypertext Transfer Protocol Secure)** is HTTP over TLS. It provides confidentiality, integrity, and server authentication. |
| **53** | **DNS** | **DNS (Domain Name System)** translates domain names into IP addresses. It primarily uses UDP port 53 and can use TCP port 53 for zone transfers and other cases requiring TCP. |
| **21** | **FTP** | **FTP (File Transfer Protocol)** is used to transfer files between systems. It transmits credentials and data without encryption. Secure alternatives include **SFTP** and **FTPS**. |
| **25** | **SMTP** | **SMTP (Simple Mail Transfer Protocol)** is primarily used to send email between mail servers. Port **587** is commonly used for email submission. |
| **3389** | **RDP** | **RDP (Remote Desktop Protocol)** allows users to remotely access Windows computers with a graphical interface. |
| **445** | **SMB** | **SMB (Server Message Block)** is used for file sharing, printer sharing, and accessing network resources, particularly in Windows environments. |
| **67/68** | **DHCP** | **DHCP (Dynamic Host Configuration Protocol)** automatically assigns IP addresses and network settings. The server uses UDP **67**, while clients use UDP **68**. |
