# AAA (Authentication, Authorization, Accounting)

## Authentication
Authentication verifies the identity of a user or system.

**Examples:**
- Passwords
- Multi-Factor Authentication (MFA)
- Biometrics

## Authorization
Authorization determines what an authenticated entity is allowed to access or perform.

**Examples:**
- Read-only access
- Administrator privileges
- Role-Based Access Control (RBAC)

## Accounting
Accounting involves recording and tracking user or system activities, such as logins, resource access, and actions performed.

**Examples:**
- Login/logout timestamps
- Audit logs
- Records of administrative actions
- Network usage records
