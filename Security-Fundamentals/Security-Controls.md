# Security Controls

A security control is a safeguard or countermeasure designed to prevent, detect, or respond to threats and reduce security risks.

**Examples:**
- Multi-Factor Authentication (MFA)
- Firewalls
- Encryption
- Endpoint Detection and Response (EDR)
- Security Information and Event Management (SIEM)

## Types of Security Controls

### 1. Based on Function

- **Preventive:** Designed to prevent attacks or unauthorized access.
  - Examples: MFA, access controls, firewalls.

- **Detective:** Designed to identify suspicious activity or security incidents.
  - Examples: SIEM alerts, IDS, security log monitoring.

- **Corrective:** Designed to remediate issues or reduce the impact after an incident.
  - Examples: Removing malware, patching vulnerabilities, restoring affected systems.

### 2. Based on Implementation

- **Technical:** Implemented using technology.
  - Examples: Firewalls, encryption, EDR.

- **Administrative:** Policies, procedures, and processes used to manage security.
  - Examples: Security policies, employee training, access review procedures.

- **Physical:** Protects physical facilities, equipment, and assets.
  - Examples: Locks, security cameras, access badges.
